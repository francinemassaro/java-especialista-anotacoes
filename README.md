# Estudos - Curso Java Especialista

Este repositório contém anotações e desafios práticos desenvolvidos durante estudo do curso **Especialista Java**.

## 📁 Organização

- `src/`: Código-fonte dos desafios práticos e exercícios
- `docs/`: Resumos e anotações escritas em Markdown
- `docs/imagens/`: Imagens utilizadas nos resumos

## ✅ Conteúdo estudado

- Plataforma Java e Ambiente
- Fundamentos da linguagem
- Estruturas de controle
- IDEs, Debug e boas práticas
- POO e paradigmas
- Clean Code
- Wrappers e tipos primitivos
- Arrays
- Gerenciamento de Memória Java
- Construtores, pacotes e visibilidade
- Encapsulamento, javaBeans e records

## 💡 Observações

Este repositório tem fins educacionais, com foco em reforçar conceitos por meio da prática e por fim especialização em 
Java.
